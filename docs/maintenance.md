# メンテナンスガイド

サイトを更新するときのファイル構成と確認手順です。
掲載内容・写真・デザインを維持し、必要な箇所を絞って更新します。

## ファイル構成

| ファイル・ディレクトリ | 用途 |
| --- | --- |
| `index.html` | HOME・プロフィール・趣味のギャラリー |
| `baseball/index.html` | 野球の観戦記録 |
| `idol/index.html` | アイドル・楽曲の一覧 |
| `car/index.html` | 愛車・パーツの一覧 |
| `boatrace/index.html` | ボートレースの観戦記録 |
| `assets/css/style.css` | 全ページ共通のスタイル |
| `assets/js/main.js` | スクロール時の表示演出 |
| `assets/images/` | プロフィール画像・各分野の写真 |
| `favicon.svg` | サイトアイコン |

## ページを更新する

### HOME

- ギャラリーの順序は BASEBALL → IDOL → CAR → BOAT RACE です。
- 写真は既存の `img` 要素で表示しています。画像を更新するときは、参照先・代替テキスト・切り取り位置を確認します。
- SNSのリンク先を更新するときは、本人のプロフィールURLを確認します。

### BASEBALL

- 観戦記録は年ごとの試合数・勝敗・引き分けを揃えて更新します。勝率は引き分けを除いて算出します。
- 写真アーカイブは現在非表示です。写真を追加する場合は `assets/images/baseball/` に保存し、`.photo-archive-grid` に `figure.archive-photo` を追加します。内容を確認してから `#photo-archive` の `hidden` 属性を外します。
- 写真のキャプションは任意です。未確認の情報は追加しません。

### IDOL

- 4グループと各3曲のお気に入りを掲載しています。曲名に順位やリンクは付けません。
- 公式リンクのテンプレートはHTMLコメント内にあります。追加する場合は正式なURLを確認してから表示します。

### CAR

- 紹介写真はHOMEと同じ画像を使用しています。
- `The Details.` は項目名とパーツ情報の2列を維持します。
- 写真アーカイブは現在非表示です。写真を追加する場合は `assets/images/car/` に保存し、`#car-photo-archive .car-photo-grid` に `figure` を追加します。内容を確認してからセクションの `hidden` 属性を外します。

### BOAT RACE

- 本文はテキストのみで構成し、写真ギャラリーは追加しません。
- 選手情報や観戦歴は、確認できた内容だけを更新します。

## 文字サイズとレイアウト

全ページが `assets/css/style.css` を共有しています。変更前に対象セレクターと後続の上書きを確認してください。

文字サイズの調整用変数は、CSS末尾の `Reading scale` ブロックにまとめています。

| 変数 | 用途 |
| --- | --- |
| `--page-heading-size` | ページタイトル |
| `--section-heading-size` | セクション見出し |
| `--body-size` | 本文・楽曲・パーツ情報 |
| `--caption-size` | 補助情報 |
| `--label-size` | 小見出し・項目ラベル |

HOMEのプロフィールはスマートフォンで縦並び、ギャラリー写真はスマートフォンで正方形・PCで縦長です。CARのパーツ一覧は2列です。文字サイズを変更するときは、行間・折り返し・周囲の余白も一緒に確認します。

## ローカルで確認

Python 3 が使える環境で、リポジトリのルートから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://localhost:8000/` を開いてください。追加パッケージのインストールは不要です。

## 共通の操作・読み込み設定

- 趣味ページ下部に4分野へのリンクがあり、現在のページには `aria-current="page"` を付けています。
- キーボード操作では最初に「本文へスキップ」リンクが表示されます。
- Google Fontsは各HTMLのheadから読み込みます。接続できない場合もシステムフォントで本文を表示します。
- 画像には実寸の幅・高さを指定し、HOMEのプロフィール画像とCARの紹介写真以外は遅延読み込みを使います。

## 更新後の確認

1. [上記の手順](#ローカルで確認)でローカルサーバーを起動します。
2. HOME / BASEBALL / IDOL / CAR / BOAT RACE の全5ページを確認します。
3. PCとスマートフォンの両方で、見出しと本文のバランス・画像の切り取り・横方向のはみ出しを確認します。650px前後のレイアウト切り替えも確認します。
4. HOMEの人名、BASEBALLの成績、IDOLの長い曲名、CARの製品名の折り返しを確認します。
5. ナビゲーション・カード・HOMEへ戻るリンク、画像・CSS・JavaScriptの相対パスを確認します。
6. タップ操作、キーボードのフォーカス、文字拡大、動きを減らす設定での表示を確認します。

Node.js が使える場合は、共通JavaScriptの構文も確認できます。

```sh
node --check assets/js/main.js
```

## GitHub Pages

このサイトはGitHub Pagesのプロジェクトサイト向けの相対パスで構成しています。

公開設定を行う場合は、リポジトリの **Settings → Pages → Build and deployment** で、Sourceを **Deploy from a branch**、ブランチを **main**、フォルダーを **/ (root)** に設定します。

公開先として想定しているURLは `https://larus-peach.github.io/peach-personal-space/` です。設定後はGitHub上の公開結果と、実際のページ・リンク・画像を確認してください。

SNS共有の設定を追加する場合は、公開URLと使用する既存画像を確認したうえで `og:url`・`og:image` などを設定します。
