# PEACH / Personal Space

野球、アイドル、車、ボートレース。好きなものや観戦の記録をまとめた、個人の趣味ポートフォリオサイトです。

余白と写真、タイポグラフィを中心にした、シンプルなデザインで構成しています。

## コンテンツ

| ページ | 内容 |
| --- | --- |
| HOME | プロフィールと、4つの趣味への入口 |
| BASEBALL | 現地観戦の記録と好きな選手 |
| IDOL | 好きなグループと楽曲 |
| CAR | 愛車の紹介とカスタマイズ |
| BOAT RACE | 好きなレーサーと観戦の記録 |

## 技術構成

HTML / CSS / Vanilla JavaScript による静的サイトです。フレームワークやビルドツールは使用していません。

## ローカルで確認

Python 3 が使える環境で、リポジトリのルートから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://localhost:8000/` を開いてください。追加パッケージのインストールは不要です。

更新方法・表示確認・GitHub Pages の設定は、[メンテナンスガイド](docs/maintenance.md)にまとめています。
